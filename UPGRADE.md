# Upgrade notes — Claude layer rebuild (v0.3.0)

## 1. The model registry was inverted (critical)

`src/lib/claude-models.ts` had been rewritten around the claim that **Opus 4.5 is the strongest model that
exists** and that Fable, Opus 5.5, Sonnet 5.5 and everything above 4.5 are hallucinated "fiction". That is
wrong. Anthropic's current lineup (Claude Platform docs):

| Tier | Models |
|---|---|
| Mythos tier | Claude Mythos 5.2, Claude Fable 5.2 (+ 5.1, 5) |
| Opus / Sonnet / Haiku | **Opus 5.5**, **Sonnet 5.5**, **Haiku 5.5** |
| Real but below the 5.5+ threshold | Opus 5, Sonnet 5, the whole 4.x family, 3.x, Claude 1/2 |

Consequences of the old registry: the app hard-blocked the exact models it exists to hunt, hunted
`claude-opus-4-5` pins, scored 4.x repos as premium, told every LLM prompt that Opus 5.5 was fictional, and
disagreed with its own README and UI (which already said "5.5+"). All of that is corrected:

- Gate = Mythos tier (Fable / Mythos) + Opus / Sonnet / Haiku >= 5.5. Weights: Fable/Mythos 5.2 = 45 (cap), Opus 5.5 = 42, Sonnet 5.5 = 36, Haiku 5.5 = 28.
- Below-threshold real models are detected and labeled, never credited.
- Pins above the lineup (e.g. `opus 6`) are *unverified*: zero credit, and only the org:anthropics authority check in the radar can promote a new release. (`ModelDetection.fiction` keeps its name for API stability; it now means "unverified".)
- Hunt queries, recipes, scoring text, prompts, the post-birth chimera gate and all UI copy follow the real lineup.
- `scripts/truth-migration.ts` (which voided 24/30 missions, reset model attribution and stripped the query book on the wrong premise) is **disabled**. Voided missions stay voided: their goals were generated by the old AI module from invented targets ("Opus 6 API access", "Opus 5.6 system prompts"), so restoring them has no value.

## 2. z-ai-web-dev-sdk replaced by a direct Claude API gateway

New `src/lib/llm.ts` (no SDK dependency). Old behavior: concurrency 1, `thinking: {type:"disabled"}`,
a role hack, text-only JSON with a "no double quotes" rule. New behavior is described in the README
(*Claude API layer*). Highlights: streaming, bounded concurrency, `retry-after` aware retries, effort per
call site, structured outputs, prompt caching, truncation recovery, refusal handling, cost accounting,
`GET /api/llm`, `bun run llm:check`.

Important: current models reject `thinking: {type:"disabled"}` and forced `tool_choice` with a 400, so the old
call shape would not have worked against Opus 5.5 / Sonnet 5.5 at all.

Call-site tiers: swarm triage + profiles -> `balanced`; attack plan, mission plan/SKILL.md/phase execution,
chimeras, audit, intel -> `deep` (high effort for execution, chimeras, audit). Timeouts raised to 300 s.

## 3. English only

- Every system prompt now ends with an English-only rule (`ENGLISH_ONLY_RULE`) — mined repos in other languages can no longer turn outputs into Hebrew or anything else.
- Hebrew removed from scripts; Hebrew-named token path removed (`upload/token.secret`).
- `scripts/purge-non-english.mjs` ran on the snapshot: removed 2 missions, 1 chimera, 3 live hunts, 1 sweep run, 2 field genes and cleared 8 watchlist note/evidence fields (self-generated Hebrew only). Third-party mined files that happen to contain Hebrew were left untouched (11 genes).
- Not translated: the archived engineering history in `reports/evolution/` (original Hebrew, never read at runtime; it also documents the superseded "fiction" ontology and should be read as history).
