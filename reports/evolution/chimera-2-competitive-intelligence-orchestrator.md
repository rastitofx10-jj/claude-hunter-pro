# Competitive Intelligence Orchestrator

## Purpose

This orchestrator autonomously hunts premium Claude projects on GitHub, extracts their DNA (skills, commands, patterns), and compiles superior chimeras that give your product competitive advantages. It combines the strengths of multiple source DNA into a unified system that learns from the entire ecosystem.

## Activation Triggers

- User requests competitive analysis of Claude ecosystem
- Need to identify premium Claude projects for DNA extraction
- Requirement to compile superior chimeras from multiple sources
- Detection of new architectural patterns or breakthrough capabilities
- Need to maintain technological superiority over Claude competitors

## Core Workflow

### Phase 1: Project Discovery

```bash
# Initialize competitive hunt
/competitive-hunt --premium-only --min-stars 100 --recent-updates
```

1. **Premium Project Detection**:
   - Search GitHub for projects using "claude", "anthropic", or "claude-*" in names
   - Filter by stars, forks, and recent activity
   - Identify premium indicators: CLAUDE.md files, .claude directories, sophisticated skill systems

2. **Project Triage**:
   - Apply bridgebuilder-review patterns to assess project quality
   - Categorize by domain: documentation systems, skill frameworks, API implementations
   - Identify architectural patterns and innovation level

3. **Authorization Check**:
   - Verify project licenses for DNA extraction
   - Check for restrictions on skill reuse
   - Document any compliance requirements

### Phase 2: DNA Extraction

```bash
# Extract project DNA
/dna-extract --project-url <github-url> --depth comprehensive
```

1. **Skill Extraction**:
   - Scan .claude/skills directories for SKILL.md files
   - Extract skill patterns, capabilities, and constraints
   - Document architectural decisions and trade-offs

2. **Command Analysis**:
   - Identify .claude/commands patterns
   - Extract automation workflows and best practices
   - Analyze permission models and security approaches

3. **Configuration Harvest**:
   - Extract .loa.config.yaml patterns
   - Document zone systems and constraint models
   - Capture quality gates and review patterns

### Phase 3: Competitive Analysis

```bash
# Analyze competitive landscape
/competitive-analysis --compare-dna --identify-patterns
```

1. **Pattern Recognition**:
   - Identify recurring architectural patterns across projects
   - Detect emerging best practices and innovations
   - Map capability gaps in your own system

2. **Breakthrough Detection**:
   - Apply continuous-learning triggers to identify non-obvious solutions
   - Detect paradigm shifts in implementation approaches
   - Identify "first-mover" advantages in new capabilities

3. **Threat Assessment**:
   - Evaluate competitive threats based on capability overlap
   - Identify potential disruptive innovations
   - Map competitive advantages and disadvantages

### Phase 4: Chimera Compilation

```bash
# Compile superior chimera
/chimera-compile --sources <dna-list> --target <capability>
```

1. **DNA Fusion**:
   - Apply principles from multiple source DNA
   - Resolve conflicts through architectural trade-off analysis
   - Create hybrid approaches that leverage the best of each source

2. **Quality Gates**:
   - Apply audit patterns from security-audit skill
   - Validate against zone system constraints
   - Test for implementation feasibility and performance

3. **Breakthrough Integration**:
   - Incorporate detected breakthrough capabilities
   - Design for future extensibility and adaptation
   - Document competitive advantages and differentiation points
